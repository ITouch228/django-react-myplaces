# Мобильный MyPlaces

Ветка `feat/mobile-offline` добавляет клиент Expo / React Native / TypeScript в каталог `mobile/`. В приложении можно искать места по названию и адресу, добавлять и редактировать места, записывать посещения с чеками, ценами и оценками блюд. Адрес и координаты можно ввести вручную.

SQLite хранит места, чеки и позиции в приватном каталоге приложения. Первый запуск создаёт схему версии 1. Места, чеки и позиции получают локальные UUID. Цены хранятся в копейках, чек и его позиции записываются в одной транзакции. Удаление места удаляет его чеки и позиции.

Для установленного приложения не нужны сервер, интернет, учётная запись или файл `.env`. Карта, GPS, перенос данных из веб-версии и резервное копирование в эту версию не входят. Удаление приложения или очистка его данных удаляет локальный журнал.

## Запуск в разработке

Понадобится Node.js 22.13+ и Expo Go с поддержкой SDK 58. ПК и телефон должны быть в одной сети для подключения к Metro.

```sh
cd mobile
npm ci
npm start
```

Открой QR-код в Expo Go. Metro использует порт `7051`. Из корня репозитория доступны `make mobile-install`, `make mobile` и `make mobile-check`.

## Android APK

Для локальной бета-сборки установи Android SDK через Android Studio и настрой Java и Android SDK для Gradle. Из корня выполни `make mobile-install`, затем `make apk`. Для сборки без Make:

=== "Windows PowerShell"

    ```powershell
    cd mobile
    npm ci
    npx expo prebuild --platform android --no-install
    cd android
    .\gradlew.bat :app:assembleRelease
    ```

=== "Linux Bash"

    ```bash
    cd mobile
    npm ci
    npx expo prebuild --platform android --no-install
    cd android
    ./gradlew :app:assembleRelease
    ```

Файл находится в `mobile/android/app/build/outputs/apk/release/app-release.apk`. Сборка использует тестовую подпись из шаблона Expo и подходит для локальной установки. Для проверки автономности используй установленный APK с включённым авиарежимом и выключенным Wi-Fi. В Expo Go приложение загружается через Metro.

## Проверка перед merge { #mobile-qa }

| Действие на телефоне | Ожидаемый результат |
| --- | --- |
| Включить авиарежим, выключить Wi-Fi, остановить Metro и открыть APK | Открывается экран «Мои места» |
| Добавить «Кафе», указать адрес, оставить координаты пустыми | Открывается карточка. В списке место находится по названию и адресу |
| Ввести только широту или долготу 181 | Появляется ошибка, введённые поля остаются в форме |
| Добавить чек с позициями «Чай» за 0,10 ₽ и «Торт» за 0,20 ₽. Второй позиции поставить 5 | Итог 0,30 ₽. В списке мест у кафе один чек и средняя оценка 5,0 |
| Изменить название места и цену одной позиции | Карточка и итог чека обновляются. Остальные позиции сохраняются |
| Принудительно остановить приложение и снова открыть APK | Место и отредактированный чек сохранены |
| Нажать «Удалить чек», сначала отменить, затем подтвердить | При отмене чек остаётся. После подтверждения чек исчезает, счётчик и средняя оценка обновляются при возврате к списку |
| Добавить ещё один чек, затем удалить место с подтверждением | Место исчезает из списка вместе со своими чеками |

Jenkins проверяет установку по lock-файлу, совместимость Expo, типы и тесты SQLite. APK собирается на машине с Android SDK.
