# HTTP API

База для локального запуска: `http://localhost:8072/api/`.

| Метод | Маршрут | Назначение |
| --- | --- | --- |
| POST | `register/` | Регистрация, выдача JWT |
| POST | `token/` | Получение access/refresh JWT |
| POST | `token/refresh/` | Обновление access |
| GET | `user/` | Текущий пользователь |
| GET/POST | `places/` | Список своих мест / создание |
| GET/PATCH/DELETE | `places/{id}/` | Карточка, изменение, удаление |
| GET | `places/nearby/?lat=&lng=&radius=` | Личные места в радиусе, км |
| GET/POST | `checks/` | Свои чеки / создание с позициями |
| GET/PATCH/DELETE | `checks/{id}/` | Чтение и изменение чека |
| POST | `checks/{id}/add_item/` | Добавление позиции |
| GET/PATCH/DELETE | `check-items/{id}/` | Операции с позицией |

Кроме регистрации и выдачи токена, защищённые маршруты требуют `Authorization: Bearer <access>`. Анонимный пользователь не получает чужие данные.

## Пример создания чека

```json
{
  "place": 1,
  "visited_at": "2026-11-13",
  "comment": "Ужин",
  "items": [
    {"item_name": "Паста", "price": "540.50", "rating": 5},
    {"item_name": "Чай", "price": "160.00", "rating": 4}
  ]
}
```

`PATCH /checks/{id}/` без `items` изменяет только переданные поля; с `items` заменяет все позиции. Поддерживается оценка 1-5, цена должна быть неотрицательной.

`nearby` принимает широту [-90;90], долготу [-180;180] и положительный радиус не более 1000 км. Некорректные параметры возвращают 400.

!!! note "Контракт стоимости"
    В текущем API `avg_price` обозначает среднюю цену позиции, а не средний чек. Не переименовывайте значение без версии API или согласованного обновления клиента.
