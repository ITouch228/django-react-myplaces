# Работа с местами и чеками

## Регистрация и вход

При регистрации ошибки показываются прямо под соответствующим полем сразу после начала ввода: минимальная длина пароля **5 символов**, несовпадение паролей, некорректный email и имя пользователя. Исправленный ввод сразу убирает ошибку. Зелёная отметка появляется при корректном значении. Доступен переключатель видимости паролей.

Если сервер отклоняет регистрацию (например, имя уже занято), сообщение отображается под нужным полем. При потере сети показывается общее уведомление, ранее введённые значения сохраняются. Во время отправки повторные нажатия заблокированы.

Формы регистрации и входа адаптированы под мобильный экран. Переходы и состояния полей используют короткие анимации; настройка системы «Уменьшение движения» отключает декоративные эффекты.

## Места

После входа открой карту. При запуске она сразу показывает сохранённые места: одно заведение по центру, несколько заведений в общем охвате. Если браузер разрешает геолокацию по HTTPS, полученные координаты автоматически становятся стартовым центром. Если GPS не доступен, карта остаётся рядом с сохранёнными местами. После ручного перемещения карта не прыгает обратно; кнопка «Моё местоположение» позволяет перейти к GPS в любой момент. Кнопка **«Мои места»** открывает список всех сохранённых заведений. В списке можно найти место по названию или адресу и отсортировать результаты по названию, рейтингу или количеству чеков. Нажатие на название переносит карту к маркеру и открывает его карточку; ссылка «Подробнее» ведёт к истории чеков. На телефоне список открывается как нижняя панель.

Чтобы добавить новое место, нажми на свободную точку карты. Откроется форма «Добавить место» с выбранными координатами. Введи **название** (обязательно) и при необходимости **адрес**, затем нажми «Сохранить место». После сохранения новое место появляется на карте и в панели «Мои места»; окно закроется. Можно нажать «Отмена», закрыть форму крестиком или клавишей Escape без создания записи. Во время отправки кнопки блокируются, а при ошибке сети появляется сообщение с возможностью повторить попытку. Открытие карточки приводит на страницу места с историей чеков. Поиск по сохранённым местам расположен **только в панели «Мои места»**: он сразу фильтрует список по названию и адресу. Отдельная строка над картой предназначена только для поиска внешних адресов.

## Чеки и история посещений

На странице места чеки отображаются спокойными карточками без задержек и последовательных анимаций. Заголовок карточки показывает дату, сумму, среднюю оценку и количество позиций. По нажатию разворачиваются блюда, комментарий и действия «Добавить позицию», «Изменить чек», «Удалить». На телефоне позиции адаптированы под узкий экран.

## Чек и оценка

На странице места нажми «Добавить чек». Укажи дату, комментарий и позиции. Для каждой позиции записываются название, цена и оценка от 1 до 5. Можно добавить несколько позиций, отредактировать или удалить запись.

Средняя цена у заведения сейчас означает **среднюю цену одной позиции**, а не средний чек. Личная оценка заведения как отдельное поле ещё не реализована.

## Известные ограничения

- Фотографии блюд и бумажных чеков пока не загружаются.
- Нет категории «Хочу посетить» и избранного.
- Есть список «Мои места» прямо на карте, но отдельная самостоятельная страница каталога ещё не реализована.
- Нет общей статистики расходов.
- Поиск по Nominatim зависит от доступности внешнего сервиса.
