# Работа с местами и чеками

## Места

После входа открой карту. Кнопка **«Мои места»** открывает список всех сохранённых заведений. В списке можно найти место по названию или адресу и отсортировать результаты по названию, рейтингу или количеству чеков. Нажатие на название переносит карту к маркеру и открывает его карточку; ссылка «Подробнее» ведёт к истории чеков. На телефоне список открывается как нижняя панель.

Чтобы добавить новое место, нажми на точку карты и введи название места. Маркер появится на карте. Открытие карточки приводит на страницу места с историей чеков. Поиск имеет режим по сохранённым местам и режим поиска адреса на карте.

## Чек и оценка

На странице места нажми «Добавить чек». Укажи дату, комментарий и позиции. Для каждой позиции записываются название, цена и оценка от 1 до 5. Можно добавить несколько позиций, отредактировать или удалить запись.

Средняя цена у заведения сейчас означает **среднюю цену одной позиции**, а не средний чек. Личная оценка заведения как отдельное поле ещё не реализована.

## Известные ограничения

- Фотографии блюд и бумажных чеков пока не загружаются.
- Нет категории «Хочу посетить» и избранного.
- Есть список «Мои места» прямо на карте, но отдельная самостоятельная страница каталога ещё не реализована.
- Нет общей статистики расходов.
- Поиск по Nominatim зависит от доступности внешнего сервиса.
